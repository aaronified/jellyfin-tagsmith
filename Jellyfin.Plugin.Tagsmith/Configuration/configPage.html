Awards

From a dataset that ships inside the plugin — no network, matched by IMDb id. Academy Awards cover every ceremony since 1927/28; BAFTA, Golden Globes and Emmys come from Wikidata, whose film-side coverage is partial, skews recent, and is thinnest for acting and directing categories (Wikidata records those on the person, not the title). Nominations include the eventual winner, so a category's nominee set is complete on its own. Enabling a namespace hands it to Tagsmith entirely: tags you added by hand under it are managed — and pruned — like generated ones.

Curated lists

list= tags for membership of well-known lists, matched by IMDb id from a dataset inside the plugin. The lists are snapshots taken when the plugin release was built. Selecting none turns the namespace off. Selecting any hands the whole list= namespace to Tagsmith: hand-made tags under it (say list=to_watch) are managed — and pruned — like generated ones, so keep personal lists in a namespace of their own.

External metadata

TMDb is built into the server and needs nothing installed. TVDb lookups need the official TheTVDB plugin (in the default catalogue); without it, series matched only by a TVDb id are resolved through TMDb where possible. Items unknown to both fall back to Jellyfin's own metadata, as does everything when this is off.

Behaviour

Covers the collections projection too: no libraries, collections, artwork or files are created or deleted, and nothing is saved back to these settings. Look for [dry-run] in the log.

Browsable collections

Several clients neither show nor filter on tags, and Jellyfin dropped tags from global search in 10.10. Projecting a namespace builds a library of collections from its tags, browsable anywhere. Tags stay the source of truth; collections are rebuilt from them on each run. Jellyfin must be able to write to its config directory.
Awards and nominations get one collection per ceremony and category — Oscar – Best Picture — and only for the ceremonies ticked above, so all four ceremonies together produce around 80 collections in each of those libraries. Nominations include the winners, so those collections are supersets of the award ones. Curated lists get one collection per list ticked above. The first sync after enabling any of these builds every collection and takes a while.
Off by default. Deleting a library in Jellyfin's own settings instead is always safe — Tagsmith notices, switches that projection off, cleans up the collections it left behind, and will not recreate it. Renaming one there is safe too; Tagsmith follows the new name. Tagsmith only ever touches libraries it created itself: if the name above is already taken by one of yours, it refuses and says so in the log.
Collection artwork is optional and ships separately. Drop images into <config>/tagsmith/thumbnails/<namespace>/ named after the tag value — india.png, bengali.png, 1950s.png — and a library tile at <config>/tagsmith/thumbnails/<namespace>.png. Case and separators do not matter. A rescan applies them wherever a collection or library has no poster, or where the image Tagsmith itself applied has changed on disk — never over a poster you set by hand. Set a poster by hand and Tagsmith copies it into that folder straight away, so it survives the collection being rebuilt.

Aliases

origin:united_states => usa rewrites within one namespace, bengali => bangla applies everywhere, and an empty replacement drops the tag. Lines starting with # are comments.
One rule ships enabled: lang:urdu => hindi (and the same for audio_lang), so Hindi and Urdu share one collection. They are separate languages on paper — separate ISO codes, Devanagari against Perso-Arabic — but on screen the difference is largely inaudible: the dialogue either side of the border is spoken Hindustani, and the script decides how the subtitles are set rather than what the film sounds like. Keeping them apart splits the same actors, the same playback singers and often the same picture across two shelves. To turn it off, write both lang:urdu => urdu and audio_lang:urdu => urdu here — two rules ship, and one line overrides only one of them. They must be scoped like that; a bare urdu => urdu will not work, because a scoped rule always beats a global one. Expect the Urdu films to move to their own collection on the next sync. If you have Remove obsolete tags switched off, the fold adds lang=hindi without removing lang=urdu, leaving those films in both collections.

Managed prefixes

Maintained automatically. Every prefix listed here is pruned and rewritten on each run, which is how renaming a namespace or turning one off still cleans up the old tags. Remove a line to make Tagsmith forget those tags and leave them alone.

Rescan

Starts the Sync Tagsmith tags scheduled task immediately. Save your settings first. Progress is shown in Dashboard > Scheduled Tasks.
Replaces the poster on every projected collection and library tile with the matching image from <config>/tagsmith/thumbnails/, overwriting posters set by hand. Items with no matching file keep what they have. A regular rescan already fills in missing posters and refreshes Tagsmith's own stale ones; this button is for discarding hand-set posters in favour of the folder — after dropping in a new set, or to undo an adoption.
Removes every collection and library Tagsmith created — the box-set entries and the libraries holding them. Your media is never touched: collections only link to movies and shows, so deleting one deletes the link, not the film. Tags are kept too. Projections left enabled above are rebuilt from the tags on the next sync; to make the deletion stick, untick them and save before pressing this. With dry run on, the deletions are only logged.
